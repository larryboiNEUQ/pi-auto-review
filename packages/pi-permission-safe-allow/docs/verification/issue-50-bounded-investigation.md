# Issue #50 — bounded reviewer investigation

Draft PR #52; isolated issue worktree `feat/issue-50-bounded-investigation`. This is an injected **fact broker** inside the existing Authorizer, not a new authority or a tool-using agent. Work remains under review; no CI/live-model outcome is claimed here.

## Capability and opt-in

- The original `readOnlyProbes` preflight still performs at most one permission-system MCP canonical-target lookup, only for an otherwise complete read-only ask missing `action.target`. `readOnlyProbes: false` disables it and all expanded investigation.
- `investigationEnabled: true` is a separate deliberate opt-in, default `false`; it is inert unless `readOnlyProbes` is also true. Chat may return a strict JSON `requestFact` for `file.metadata`, `file.text`, or `repository.metadata`. The file path must literally match the current action's inert `path` field. Repository identity is only the current cwd's permitted `package.json` name/version, not arbitrary Git config or commands.
- The injected `PermissionQuery.readPermittedLocalFact` is optional; absence denies, never falls back to direct filesystem access. The permission system checks the current `read` and explicit `path` policy, cwd containment, symlink components and regular-file type, then rechecks policy after closing a hard-bounded read. It rejects UNC/device entrypoints on Windows before path resolution, sensitive names/content, binary and oversized text. No general shell/eval, arbitrary tool/MCP dispatch, network, credential store, mutation, permission edit or approval API is available.
- Hard limits: 4 KiB UTF-8 text (64 KiB metadata file-size ceiling), at most 250 ms waiting per local fact call, two broker calls and three total chat reviewer invocations per ask. The finite `timeoutMs` deadline starts before canonical preflight and covers auth, all review rounds and probes. The existing canonical-target hop is separately capped at one; `probeTimeoutMs` is at most 5 seconds.
- The broker validates typed inert inputs, binds results to `requestId`, `exactActionId`, requested path and canonical source path, rejects recognizable secrets, and labels results untrusted. `probe.completed` must be durably audited **before** any subsequent model call. Each augmented dossier is re-admitted to the bounded request window; pending steering, permission revocation, session/branch/config/evidence changes invalidate the result before further inference or release, including revocation while reviewer authentication is pending. A currentness guard runs again after authentication immediately before inference. The absolute deadline and cancellation are rechecked after model responses and final audit. Ordinary completed refusals still reach native terminal authority; probe, deadline, cancellation, cap and audit failures deny without that fallback.
- Jev stays on its configured evaluation backend: no interactive broker operation is simulated, and only eligible deterministic canonical-target preflight is included with the same untrusted evidence provenance. Its state explicitly says interactive investigation is unsupported; no silent model switch.

## Verification and boundaries

Primary seam: real Agent dispatcher → Gate → registered reviewer → Authorizer/terminal → disposable executor sentinel. A scripted chat fact request leaves the sentinel untouched until an audited fact is presented and a second current-ask decision allows it. Gate tests also cover sufficient evidence with zero probes, audit failure with no terminal fallback, third-request exhaustion, revocation after capture or during second-round authentication, deadline crossing during inference or final audit, cancellation, missing capability, oversized files, and invalid/disabled/out-of-action requests. Focused query tests cover path policy, cwd/symlink/UNC/FIFO/credential restrictions, and broker tests cover typed input, cancellation/timeout and redaction. Run `npm run check`, `npm test`, `npm run build && npm run build -- --check`, `git diff --check`; obtain independent review, merged-PR-worktree verification and exact-head macOS/Windows CI before closing #50. Scripted model fixtures prove routing, not live-model judgment.

Rollback: set `investigationEnabled: false` to disable interactive fact requests, or `readOnlyProbes: false` to disable all probes. Existing policy files, reviewer backend selection, and deterministic gates are unchanged. This is not Codex's OS containment: Pi has no OS sandbox, and Node filesystem checks cannot prevent an adversarial local process from racing parent-directory mutation. No guarantee is claimed for unrecognized secrets or dynamic file stability after a fact is read. Such uncertainty remains a reason for the reviewer to deny.
